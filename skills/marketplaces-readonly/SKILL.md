# WB и Ozon — только чтение

Установи один MCP-сервер `marketplaces-ru-readonly` в Codex, Claude Code или
сразу в оба обнаруженных клиента. Он предоставляет аналитику
WB, Ozon Seller и Ozon Performance, но не инструменты изменения цен, остатков,
карточек, ставок или бюджетов.

## Установка

Если рядом с этим скиллом доступен корень репозитория с `install.py`, запускай
его. Если установлен только скилл, используй `scripts/install.py`: он загрузит
публичный релиз во временную папку и запустит тот же установщик.

Обычная установка:

Запусти `python3 scripts/install.py` на macOS/Linux или
`py -3 scripts\install.py` на Windows. Параметр `--client auto` используется по
умолчанию и настраивает все найденные клиенты. Для явного выбора используй
`--client codex` или `--client claude-code`.

Если API WB/Ozon не отвечает именно при включённом VPN, после объяснения
сетевого эффекта используй `--direct-network auto`. На macOS обычно выбирается
`en0`, на Windows — первый активный физический адаптер, на Linux — первый
активный обычный IPv4-интерфейс. Для явного выбора добавь `--interface`:

```bash
python3 scripts/install.py --direct-network auto --interface en1
```

На Windows пример выглядит так:

```bat
py -3 scripts\install.py --direct-network auto --interface "Wi-Fi"
```

Этот режим привязывает исходящие соединения MCP к локальному
адресу физического интерфейса: общий VPN не выключается, но запросы этого
процесса могут идти через обычного провайдера. Это не гарантирует обход VPN Kill
Switch. Не включай режим без согласия пользователя.

Установщик сам:

- копирует сервер в стабильную папку `~/.marketplace-mcp/readonly-app`;
- создаёт отдельное Python-окружение и ставит зависимости;
- регистрирует MCP через `codex mcp add` и/или `claude mcp add --scope user`;
- предлагает ввести ключи без отображения символов;
- хранит их в `~/.marketplace-mcp/cabinets.json`, а не в репозитории или Codex-конфиге.

Никогда не проси присылать API-ключи в чат и не передавай их аргументами
командной строки. Если среда не позволяет безопасный интерактивный ввод,
попроси пользователя выполнить установочную команду в локальном Терминале.

## Проверка

После установки попроси полностью перезапустить Codex или Claude Code и
проверить `/mcp`.
Затем выполни только безопасные запросы:

1. `wb_check_auth`, `ozon_check_auth`, `ozon_perf_check_auth` для подключённых API.
2. По одному небольшому запросу чтения: продажи/остатки WB, товары/остатки Ozon,
   список рекламных сущностей Ozon Performance.
3. Если при VPN есть тайм-аут, проверь наличие IPv4 у выбранного интерфейса и
   повторно запусти установщик с `--direct-network auto --interface <имя>`.

Не трактуй 401/403 как сетевую ошибку: это ключ или его права. Не публикуй
полные ответы API — они содержат коммерческие данные продавца.
