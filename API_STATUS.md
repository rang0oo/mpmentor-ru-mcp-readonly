# Состояние API-покрытия

Дата проверки: 9 октября 2026 года.

- Основа: открытый проект `ilyautov/marketplaces-mcp-ru` v0.6.1. Каталог WB содержит 304 операции. Приоритетные read-only методы Ozon Seller обновлены по официальному Swagger 2.1; каталог Ozon Performance синхронизирован с официальным Swagger 2.0 и содержит 45 актуальных операций.
- WB: чтение текущих остатков на складах WB переведено со старого Statistics API на Analytics stocks report; чтение остатков склада продавца FBS вынесено отдельно. Удалены отключённые `GET /api/v1/supplier/stocks`, `GET /api/v5/supplier/reportDetailByPeriod` и `POST /adv/v2/fullstats`; их актуальные замены уже есть в каталоге. Авторизация приведена к формату `Authorization: Bearer <token>`. Методы сверены с [официальной документацией WB](https://dev.wildberries.ru/en/openapi/api-information) и [журналом изменений](https://dev.wildberries.ru/release-notes).
- Ozon Seller: FBS list/unfulfilled обновлены до v4, FBO list — до v3, отзывы — до v2. Добавлены раздельные остатки FBO, финансовые начисления и аналитика локальности продаж. Загруженный официальный Swagger содержит 462 неустаревшие операции; в публичной read-only поверхности намеренно доступны только проверенные методы чтения. Старые редкие операции исходного полного каталога могут требовать отдельной миграции перед использованием через не-read-only сервер.
- Ozon Performance: добавлена статистика товаров `/api/client/statistics/products/sku`, три deprecated-метода удалены. Изменяющие GET/PATCH-методы ставок и состояния кампаний явно помечены как `write` и не доступны через read-only сервер. Официальная документация: [Ozon Seller API](https://docs.ozon.ru/api/seller/) и [Ozon Performance API](https://docs.ozon.ru/api/performance/).
- Живые запросы требуют собственных ключей пользователя. В публичной копии тесты работают офлайн и изолированы от локального хранилища ключей.

Обновление каталогов по официальным спецификациям нужно проводить отдельно, с проверкой каждого нового POST-метода: часть POST читает, часть меняет данные. До такой проверки новые операции не добавляются автоматически в read-only поверхность.
