# Изменения

## Следующая версия

- Ozon Seller обновлён по официальному Swagger 2.1: FBS v4, FBO v3, отзывы v2, остатки FBO, начисления и аналитика локальности продаж.
- Ozon Performance синхронизирован с официальным Swagger 2.0: добавлена статистика товаров, удалены deprecated-методы.
- Исправлена опасная классификация изменяющих GET-методов Performance: включение, выключение и изменение ставки больше не попадают в read-only поверхность.

## 0.1.0 — подготовка публичной read-only версии

- Отдельная точка входа MCP для Wildberries, Ozon Seller и Ozon Performance с 45 инструментами чтения.
- Разделены текущие остатки на складах WB и остатки продавца FBS; старый метод WB Statistics удалён из рабочих сценариев.
- Авторизация WB приведена к текущему формату Bearer; из каталога удалены три отключённых метода, добавлена проверка параметров остатков и цен.
- Тесты изолированы от локальных ключей пользователя.
- Убраны старые установщики, публикационные настройки и инструкции исходного проекта; опубликована новая инструкция для Codex.

Исходный проект: [ilyautov/marketplaces-mcp-ru](https://github.com/ilyautov/marketplaces-mcp-ru), версия 0.6.1, лицензия MIT.
