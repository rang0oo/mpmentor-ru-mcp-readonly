# Безопасность

Сервер публикует только инструменты чтения, но ваши API-ключи могут иметь более широкие права на стороне WB/Ozon. Выдавайте им минимальные права и не подключайте другие серверы, если не намерены разрешить изменения.

Ключи должны оставаться за пределами Git и чата, например в локальном `~/.marketplace-mcp/cabinets.json` (режим 600). Офлайн-тесты изолированы от этого файла. При подозрении на утечку отзовите и перевыпустите ключ в кабинете маркетплейса. Не публикуйте сами ключи или полные ответы API в issue.

Для сообщения об уязвимости воспользуйтесь приватным Security Advisory в репозитории GitHub, когда он будет опубликован.
