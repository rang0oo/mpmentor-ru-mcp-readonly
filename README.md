# MPMentor RU MCP Readonly

Wildberries и Ozon в Codex — версия только для чтения.

Независимая адаптация [marketplaces-mcp-ru](https://github.com/ilyautov/marketplaces-mcp-ru) (MIT). Подключает Codex к Wildberries, Ozon Seller и Ozon Performance через локальный MCP-сервер. Вы можете спросить о продажах, заказах, остатках на складах WB и продавца FBS, товарах, ценах, финансах и рекламе. Этот сервер **не показывает инструментов изменения или удаления**. Он не меняет остатки, цены, карточки и рекламные настройки.

> Проект не содержит чьих-либо API-ключей. Ключи хранятся только на вашем компьютере. Для WB выбирайте токен с правами чтения и нужными категориями; для Ozon — отдельные Seller и, при необходимости, Performance ключи с минимально доступными правами. Если платформа не позволяет выдать строго read-only ключ, ограничение обеспечивается только этим MCP-сервером: не запускайте другие серверы из исходного проекта с тем же ключом.

## Установка в Codex или Claude Code

Нужны Python 3.10+, интернет и хотя бы один установленный клиент: Codex или
Claude Code. Установщик автоматически найдёт их; если установлены оба — подключит
MCP к обоим.

**Через скилл.** Передайте Codex ссылку на этот репозиторий и попросите:

> Установи skill `marketplaces-readonly` из этого репозитория и настрой read-only MCP.

После установки скилла попросите: «Подключи мои кабинеты WB и Ozon». Скилл
запустит встроенный установщик. Ключи вводятся только в локальном Терминале со
скрытым вводом — не отправляйте их в чат.

**Напрямую из репозитория на macOS/Linux:**

```bash
git clone https://github.com/rang0oo/mpmentor-ru-mcp-readonly.git
cd mpmentor-ru-mcp-readonly
bash install.sh
```

**На Windows:** скачайте и распакуйте ZIP репозитория, откройте его папку в
PowerShell или Command Prompt и выполните:

```bat
install.bat
```

При необходимости можно выбрать только один клиент:

```bash
bash install.sh --client codex
bash install.sh --client claude-code
```

На Windows те же параметры передаются после `install.bat`.

Установщик автоматически:

- копирует приложение в стабильную папку `~/.marketplace-mcp/readonly-app`;
- создаёт отдельное Python-окружение и устанавливает зависимости;
- регистрирует один сервер `marketplaces-ru-readonly` через официальный CLI
  Codex и/или Claude Code;
- предлагает скрыто ввести ключи WB, Ozon Seller и Ozon Performance;
- не помещает ключи в репозиторий, историю команд или конфигурацию Codex.

Полностью перезапустите Codex или Claude Code, откройте `/mcp` и проверьте сервер
`marketplaces-ru-readonly`.

## Работа при включённом VPN

Если обычная установка работает без VPN, но запросы WB/Ozon получают тайм-аут
при включённом VPN, переустановите сервер в режиме привязки к физическому
интерфейсу:

```bash
bash install.sh --direct-network auto
```

На macOS автоматически проверяется `en0`, на Windows — активный физический
сетевой адаптер, на Linux — активный обычный IPv4-интерфейс. Можно выбрать
интерфейс явно:

```bash
bash install.sh --direct-network auto --interface en1
```

Windows:

```bat
install.bat --direct-network auto --interface "Wi-Fi"
```

Можно также указать конкретный локальный IPv4 вместо `auto`. Настройка встроена
в HTTP-клиент проекта, поэтому отдельные `sitecustomize.py`, обёртки и абсолютные
пути не нужны. Адрес определяется автоматически на компьютере пользователя.

Это не сторонний прокси и не дополнительный туннель. Общесистемный VPN не
отключается, однако соединения этого MCP-процесса могут пойти через обычного
провайдера. Решение не гарантирует обход любого VPN или его Kill Switch. Чтобы
вернуться к обычной маршрутизации, повторите установку с
`--direct-network off`.

## Добавление ключей

Не вводите ключи в чат и не добавляйте их в файлы репозитория. Установщик
сохраняет их в локальном файле `~/.marketplace-mcp/cabinets.json` с правами 600;
формат описан в [примере](docs/CREDENTIALS_EXAMPLE.md). Также поддерживаются
переменные окружения `WB_API_TOKEN`, `OZON_CLIENT_ID`, `OZON_API_KEY`,
`OZON_PERF_CLIENT_ID`, `OZON_PERF_CLIENT_SECRET`. Не вставляйте реальные
значения в команду `codex mcp add`: они попадут в историю терминала или конфиг.

## Примеры запросов

- «Покажи продажи WB за последние 7 дней».
- «Сравни остатки на складах WB и моём складе FBS; ничего не изменяй».
- «Какие товары Ozon FBS ожидают отгрузки?».
- «Покажи рекламные кампании Ozon с высоким ДРР».

Не все методы API доступны каждому кабинету: нужны права токена, подписка на некоторые функции и актуальная документация площадки. Актуальность покрытия и ограничения перечислены в [API_STATUS.md](API_STATUS.md). Методы каталога можно искать через `*_search_methods`, а безопасные операции чтения запускать через `*_call_method`.

## Безопасность и ограничения

Публичная точка входа `readonly_mcp.server` содержит фиксированный список инструментов чтения. В ней нет `write_method`, `delete_method`, `write_raw`, `delete_raw`, установки цен, обновления остатков и переключения кабинетов. Универсальный `call_method` сверяет класс безопасности операции перед запросом. Некоторые операции чтения Ozon и WB технически используют HTTP POST. Сервер также содержит исходный код базовых модулей; поэтому важно подключать к Codex только `readonly_mcp.server`, а не модули отдельных маркетплейсов.

Сервер работает локально через stdio. Не открывайте его по HTTP в интернет без отдельной аутентификации. Живые запросы к WB/Ozon могут возвращать коммерчески чувствительные данные; не публикуйте ответы целиком.
